# python-aulas

Repositório de estudos de Python, com os exercícios e testes feitos ao longo das aulas.

## Organização

Cada aula fica em uma pasta própria, nomeada no formato `aulaNN`:

```
python-aulas/
└── aula09/
    └── teste.py
```

- `aula09/`: arquivos da aula 9. Por enquanto contém apenas `teste.py`, ainda vazio.

Novas aulas devem seguir o mesmo padrão (`aula10/`, `aula11/` e assim por diante).
